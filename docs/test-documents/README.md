# Synthetic test documents

These examples use fictional patient and hospital information for testing only.

Each case has its own folder:

- [D01](D01/): cataract case, including scanned and digital files.
- [D02](D02/): carpal tunnel case, including separate and combined PDFs.
- [D03](D03/): hydrocele case.
- [H01](H01/), [H02](H02/), [H03](H03/), [H04](H04/), [H05](H05/) and [H06](H06/): varied hospital claim examples.
- [Riverbend](Riverbend/), [Sunrise](Sunrise/), [Greenfield](Greenfield/), [Lakeshore](Lakeshore/) and [Citycare](Citycare/): earlier hospital and OCR examples.

Use only documents belonging to the same patient in one claim. Files within a hospital folder are examples and should be checked for patient details before combining.

See the [demo guide](demo-cases-guide.md), [H-series guide](hospital-claim-cases-guide.md), and [OCR examples guide](hospital-ocr-examples-guide.txt). Policy wordings remain in `healthcare/policy_fixtures/`.
